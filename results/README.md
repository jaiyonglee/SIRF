# Results Directory

This directory stores all intermediate and final outputs generated by SIRF (Spatial Inference and Reconstruction Framework).
Each run creates a subfolder named after config['data']['dataset'] (e.g., demo, korea_100p_0033).

---

## Processing Order (modules → output folders)

Step	Module	Purpose	Output
1	search.py	Builds the seed topology from inputs/config. Performs ID normalization, duplicate-edge merging, island pruning, and candidate-edge search with plausibility checks. Produces baseline bus.csv / branch.csv used downstream.	Searched_data/
2	Initialize.py	Initializes node and branch parameters (initial coordinates, connectivity).	Initialized_data/
3	Data_Scaling.py	Scales and normalizes coordinates; records missing positions.	Preprocessed_data/
4	Linear_Regression.py	Fits spatial regression models and regresses branch data.	Regressed_data/
5	Inference.py	Performs reclassification and inference to reconstruct missing node coordinates, evaluates loss, filters nodes.	Inferred_data/
6	Align_Node.py	Final alignment of inferred results to ground-truth coordinates and exports aligned network.	Aligned_data/

## Key Files by Stage

Searched_data
- bus.csv : Seed nodes with normalized IDs and attributes; anchor flags when available.
- branch.csv : Seed edges after deduplication and pruning (multi-edges merged, islands removed).

Initialized_data
- Bus_initialized_.csv / Branch_initialized_.csv : Initialized states for inference start.

Preprocessed_data
- Bus_scaled_*.csv : Scaled/normalized coordinates.
- Bus_nan_*.csv : Nodes with missing positions.
- Branch_detailed_*.csv : Expanded branch info.

Regressed_data
- Model_regressed_*.csv : Regression parameters.
- Branch_regressed_*.csv : Regressed branch outputs.

Inferred_data
- Bus_inferred_.csv / Branch_inferred_.csv : Inference results.
- Inference_loss_*.csv : Loss trace per iteration.
- Filtered_nodes_.csv, Distance_rate_.csv, Bus_nan_*.csv : Diagnostics/supporting artifacts.

Aligned_data (final)
- Bus_aligned_.csv / Branch_aligned_.csv : Final aligned outputs for visualization/evaluation.

---

## How to Run

python sirf.py –config configs/default.yaml

The framework automatically:
	1.	Runs search → initialize → scale → regress → infer → align
	2.	Creates results/<dataset_name>/
	3.	Saves intermediate and final CSVs in the structure above

---

## Notes
- Generated CSVs are large and should be excluded via .gitignore
- All outputs are reproducible by re-running with the same configuration
- File suffixes such as _100p_0033 indicate dataset version or seed index
